# Illustrations d’arrière-plan

Ce dossier accueille les SVG institutionnels destinés aux fonds des pages
(accueil, connexion, inscription, espaces profils).

Les fichiers existants de `assets/` et les gravures intégrées dans
`js/views/home.js` ne doivent **pas** être remplacés par des placeholders.

## Emplacements prévus

| Fichier recommandé | Usage |
|---|---|
| `home-hero.svg` | Accueil — section héro |
| `home-process.svg` | Accueil — circuit |
| `home-values.svg` | Accueil — valeurs |
| `auth-aside.svg` | Connexion / inscription — panneau gauche |
| `portal-hero.svg` | Espaces entreprise / personne — bandeau |
| `ws-hero.svg` | Espaces internes — bandeau |

Convention : SVG, traits `#5b7791`, sans texte, fond transparent, < 40 Ko.
Voir `docs/design-reference.html` pour le brief complet.
