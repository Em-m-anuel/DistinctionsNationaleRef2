# Référence de conception GAB-ORIENT

Ce dossier est **une copie du prototype** [`DistinctionsNationaleReference`](https://github.com/Em-m-anuel/DistinctionsNationaleReference.git).

Il sert de **modèle visuel et comportemental**. Ce n’est pas l’application métier.

- Ne pas remplacer `index.html`, `js/` ou `css/` du dépôt parent par ces fichiers.
- Ne pas mélanger `GO_DATA.seed` avec le magasin `dn.cf.store.v1`.
- Lancer : `python3 -m http.server 8010` depuis ce dossier, puis ouvrir `/`.

Documentation : `DESIGN_REFERENCE.md`, `PAGES_MAP.md` (24 vues / 14 profils), `ROLE_COMPONENT_MAPPING.md`.

Le dépôt `DistinctionsNationaleRef.git` est une copie de FrontII, **pas** la source d’écrans. La source est `DistinctionsNationaleReference` (ce dossier).
