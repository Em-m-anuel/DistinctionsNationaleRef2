Identité visuelle

Plateforme de dépôt, de suivi et d’attribution des médailles et diplômes honorifiques. Caractère institutionnel gabonais : drapeau (vert, jaune, bleu), papier administratif, gravure, sobriété. Ambiance : calme, officielle, lisible. Principes : contraste texte/fond élevé, pas d’aplats saturés sur les surfaces de lecture, ornements en arrière-plan uniquement.

DIRECTION ARTISTIQUE

Papier grainé assets/paper-grain.svg, fonds blanc / blanc cassé, liseré tricolore 3 px en tête, sceau « Honneur et mérite », médailles conceptuelles en SVG (pas de photographies officielles).

CE QU’IL NE FAUT PAS FAIRE

Pas de néon, pas de glassmorphism excessif, pas de photographies génériques présentées comme des lieux réels, pas de blason officiel recréé, pas de texte dans les gravures de fond.

Illustrations d’arrière-plan

Style attendu : line-art élégant, papier gravé, dessin institutionnel. Motifs gabonais (silhouette du pays, palmes, colonnes, fronton) en contours visibles mais atténués (opacité 0.32–0.64). Jamais par-dessus le texte : masques en dégradé vers le transparent. Animation de tracé possible, lente.

Zone d’exemple — gravure bleu-gris #5B7791, sans remplissage saturé, sans photographie.

Formats : SVG propres, viewBox stable, traits stroke="#5b7791", pas de filtres lourds, < 40 Ko. Livraison dans assets/illustrations/.

Brief pour l’agent illustration

  • Objectif — fonds décoratifs compatibles avec le frontend actuel, lisibilité du texte prioritaire.
  • Motifs — silhouette du Gabon, palmes, colonnes toscanes, fronton, faisceau tricolore en liseré, médailles en contour. Pas de blason officiel.
  • Niveau de détail — gravure, pas de réalisme photographique. Peu de hachures serrées.
  • Couleurs autorisées — #5b7791, #829cb4, #c9d4df, liseré #009b62 / #d6a72c / #315c91. Fond transparent.
  • Contraste — le dessin reste sous le texte ; opacité maximale ≈ 0.64, souvent 0.36–0.45 près des titres.
  • Composition — ancrer dans un angle ou une marge. Préserver une zone centrale / gauche vide pour titres et formulaires.
  • Zones de texte à préserver — 64 px sous le header, colonne de lecture max ≈ 780 px, champs de formulaire, tableaux.
  • Variantes — accueil (large), connexion (panneau gauche), portail demandeur, espaces internes. Une variante plus légère pour mobile.
  • Animations — tracé progressif optionnel, 8–17 s, désactivable. Pas de parallaxe violent.
  • Performance — un SVG par section, pas de bitmap 4K, pas de filtres SVG coûteux.
  • Nommage — home-hero.svg, home-process.svg, auth-aside.svg, portal-hero.svg, ws-hero.svg.

Préparer l’intégration future

Dossier : assets/illustrations/. Ne pas remplacer les gravures actuelles de js/views/home.js par des placeholders. Quand les SVG arriveront, les référencer dans les bandeaux existants (.portal-hero-art, .ws-hero-art, aside de connexion) sans changer le système graphique.

Exigences responsive

Desktop : header 64 px, onglets horizontaux, menus en overlay. Tablette (≤ 760 px) : header 60 px, menus qui s’ouvrent sous l’entrée, cartes en une colonne. Mobile (≤ 520 px) : tabs en défilement horizontal, tableaux en scroll, modales max 85 dvh, bouton retour 44 px. Les gravures d’accueil sont masquées ou atténuées sous 1023 px / 639 px — les nouvelles illustrations doivent suivre la même discipline.
